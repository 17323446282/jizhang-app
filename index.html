    设置

    云端同步（Supabase）

    配置后，数据会在电脑 / 手机 / 平板之间自动同步。需先自建一个 Supabase 项目并建表（SQL 见底部）。未配置时所有数据仅存在本机。

    未连接

    第一步：在 Supabase 后台 → SQL Editor 粘贴并执行下面这段（建表 + 关闭安全限制）：
    create table if not exists finance_sync (
      sync_code text primary key,
      data jsonb not null default '{}'::jsonb,
      updated_at timestamptz default now()
    );
    alter table finance_sync disable row level security;
    第二步：在本页填好「同步码」（多设备填同一个），点「保存并连接」即自动同步。

    记账周期

    例：设为 11，则每月 11 日 ~ 次月 10 日为一个记账月。

    数据备份与恢复

    重要：建议定期把备份文件发到自己邮箱或网盘，防止设备丢失 / 换机导致数据丢失。
